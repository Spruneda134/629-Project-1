# Exercise Tracker

## Description

Exercise Tracker is an application that helps users track their workouts and monitor their progress over time. Users can create workout sessions, add activities with relevant metrics, track personal records, set goals, and generate summary reports.

## Features

* **Workout Sessions** - Create and organize workout sessions.
* **Activity Tracking** - Add exercises and keep track of metrics such as weight and reps.
* **Personal Records** - Track and view personal records for activities.
* **Goals** - Set goals and track their progress.
* **Summary Reports** - View statistics and an overview of past workouts.

## Project Structure

* **CategoryTracker** - Manages a collection of workout sessions.
* **Session** - Represents a workout session containing multiple activities.
* **Activity** - Represents an exercise and its associated metrics.

## User Stories

1. As a user, I want to add activities to a session so I can track relevant metrics.
2. As a user, I want to add sessions to a tracker so I can keep track of my workouts.
3. As a user, I want to obtain personal records so I can track my progress.
4. As a user, I want to set goals so I can stay on track with my targets.
5. As a user, I want to obtain a summary report so I can get a high-level overview of my workouts.
